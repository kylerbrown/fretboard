# Five-String Banjo Fretboard Memorizer

A single-page web app to practice memorizing the fretboard of a five-string banjo. Tuning is configurable (e.g. standard gDGBD, Double D aDADE). Click fret positions to reveal notes; use "Find all [note]" to practice locating a specific note, then "Check work" to see how you did.

## Try it

Open `index.html` in a browser, or use [GitHub Pages](https://pages.github.com/) after pushing this repo to GitHub.

## GitHub Pages (share with friends)

1. Push this repo to GitHub (see below if you haven't yet).
2. In the repo on GitHub: **Settings → Pages**.
3. Under **Source**, choose **Deploy from a branch**.
4. Branch: **main**, folder: **/ (root)**. Save.
5. After a minute or two, the site will be at `https://<your-username>.github.io/fretboard/`.

No build step required—just HTML, CSS, and JavaScript.
